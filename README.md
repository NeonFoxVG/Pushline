# Pushlinee [WIP]

Pushline is a Unity arcade car game where two cars compete in a small floating arena. The objective is to knock the opposing car off the platform.

## Features

- Arcade car movement
- Drifting mechanics
- Exaggerated collision physics

## Built With

- Unity 2022.3
- C#

## Controls

| Action | Key |
|--------|-----|
| Move Forward | W |
| Move Backward | S |
| Turn Left | A |
| Turn Right | D |
| Drift | Left Shift |

## Future Improvements

- Score and round system
- AI opponent
- Multiple arena maps
- Sound effects and particle effects
